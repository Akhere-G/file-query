# IT Security Guide

## Passwords

Passwords must be changed every ninety days and must be at least fourteen characters long. Passwords may never be shared with colleagues or written down. Use the company password manager to generate and store credentials.

## Remote access

Multi-factor authentication is required for the VPN and for every cloud application. Authenticator apps are preferred over text messages. Access to the VPN is removed automatically when an employee leaves the company.

## Lost or stolen devices

A lost or stolen laptop must be reported to the security desk within twenty four hours. The security team will lock the device remotely and rotate any credentials that were stored on it.

## Phishing

Suspicious emails should be forwarded to the phishing report mailbox and then deleted. Never click links or open attachments in messages from unknown senders.
